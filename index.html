Profile

Class 10 by day, shipping by night — balancing board exams with pull requests, and choosing hand-written code over drag-and-drop, every time.

AeroLink

An ESP32 Wi-Fi range extender that replaces a ₹5,000 box with a ₹500 chip. Written in C on ESP-IDF and managed from a frosted-glass web dashboard it serves itself: network scanner, firewall ACLs, port forwarding, DHCP reservations, OTA updates, and Home Assistant over MQTT.
