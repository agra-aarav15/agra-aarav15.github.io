Profile

Class 10 by day, shipping by night — balancing board exams with pull requests, and choosing hand-written code over drag-and-drop, every time.

I build software, and I don’t much care where it runs — browsers, servers, or a six-dollar chip. On the web, that means responsive Tailwind layouts and React front-ends with an obsessive eye for type and motion.

Lower down the stack, it means Python utilities and C firmware — most recently AeroLink, a Wi-Fi range extender that serves its own glass dashboard.

Based in Prayagraj, India. Class 10 at MPVM, CBSE.
